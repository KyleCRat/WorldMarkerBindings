# World Marker Bindings
World Marker Bindings is a lightweight addon that adds direct keybindings for World Markers, including placing markers at your cursor position. It removes the need to create and manage marker macros.

## Features
- Keybindings for World Markers
- Keybindings for clearing all World Markers
- Keybindings for placing World Markers at cursor position
- Works in combat (secure action buttons)
- No external dependencies
